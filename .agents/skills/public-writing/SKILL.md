# Public writing

Read [the writing contract](references/writing-contract.md), then the copied
[no-ai-slop rules](references/no-ai-slop-rules.md) and
[evaluation checklist](references/no-ai-slop-evaluation.md).

Name the real command, callback, setting, class, or failure behavior. Verify
claims against `tthblock.lua` and `docs/references.md`. Preserve technical names
and the writer's voice. Explain a non-obvious condition in a comment rather than
repeating the next statement. Detection reports quote a short passage and name
its pattern; do not claim AI authorship or send prose to a remote detector.

Keep commands, permissions, defaults, and failure behavior consistent across
the README, source header, runtime help, and architecture reference. Describe
actual verification and keep live hub checks distinct from offline tests.
