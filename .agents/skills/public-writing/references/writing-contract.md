# Public writing contract

Use the copied Peter Yang rules and evaluation without submitting repository
text to an external detector. Preserve the MIT notice and pinned-source hashes.

Write for a hub administrator installing this one Lua file or an agent changing
its callbacks. State the command, required class, effective setting, persistence,
or failure behavior. Use examples already supported by source or tests. Do not
claim complete deployment compatibility from an offline test or confuse this
script's feed with Ledokol's feeds.

Keep authored copy free of filler, promotional claims, rhetorical contrasts,
decorative dashes, and claims about what an AI detector knows. Preserve exact
technical casing, commands, primary source titles, and licensed source quotations.
Use headings/tables only when they help a reader find or compare information.

Comments describe non-obvious invariants. Keep full command information in the
README and script header, and make runtime help reflect configured values.
